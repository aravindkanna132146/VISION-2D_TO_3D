### 🎨 Tips for Pre-production Capture:
1. **Screen Resolution**: Record in **1920x1080 (HD)** standard using OBS Studio or Loom.
2. **Tab Zoom**: Set Chrome/Brave browser zoom to **90%** to ensure header widgets and canvas docks have maximal viewing area.
3. **Cursor Settings**: Enable a subtle cursor highlight bubble, making it easy to track mouse movement.
4. **Transition Style**: In video editing, use quick cross-fades (`0.2s` duration) when jumping between the Landing Page, Login, and Dashboard.
